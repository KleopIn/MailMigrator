## Что это

**Mail Migrator** — настольное Windows-приложение (WPF / .NET 8), которое переносит почту
из одного IMAP-ящика в другой: читает письма из источника и складывает их в назначение,
сохраняя флаги, дату и структуру. Работает с любыми IMAP-серверами: Gmail, Яндекс Почта,
mail.ru, Microsoft Exchange и другими.

Запускается одним файлом `MailMigrator.exe` — без установки, без сервера и без доступа к консоли Exchange.

## Ключевые возможности

- 🔁 **IMAP-to-IMAP** — источник и назначение подключаются напрямую, по любому хосту/порту.
- 🧹 **Дедупликация по `Message-ID`** — уже перенесённые письма не копируются повторно.
- 📅 **Фильтр по периоду** — можно перенести письма только за нужный диапазон дат «с… по…».
- 🛡️ **Защита от повторов в INBOX** — граница по дате самого старого письма на назначении:
  письма новее не дублируются, даже если при переносе `Message-ID` изменился.
- 📦 **Пропуск крупных писем** — письма больше лимита (по умолчанию 18 МБ — жёсткий потолок
  `IMAP APPEND` на Exchange) помечаются отдельно, а не ломают миграцию.
- 🏷️ **Сохранение флагов и даты** — прочитано/не прочитано, отвечено, `INTERNALDATE` переносятся.
- ⏱️ **Троттлинг** — настраиваемая задержка между письмами + экспоненциальный откат при ошибках.
- 🔐 **Пароли шифруются (DPAPI)** — учётные данные хранятся только на этом компьютере,
  в защите Windows текущего пользователя. В коде и в файлах профиля паролей в открытом виде нет.
- 📋 **Журнал в реальном времени** — каждая операция логируется, в конце — понятная сводка
  (перенесено / ошибки / уже было / крупные / вне периода).

## Установка

Бинарник `MailMigrator.exe` (x64, self-contained) скоро появится в Releases.
Пока — соберите из исходников по инструкции ниже.

> ⚠️ Windows может показать предупреждение SmartScreen (нет цифровой подписи) — нажмите
> «Подробнее», затем «Выполнить в любом случае».

### Сборка из исходников

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
git clone https://github.com/KleopIn/MailMigrator.git
cd MailMigrator
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
# результат: publish/MailMigrator.exe
```

## Использование

1. **Источник**: логин = полный e-mail, пароль = **пароль приложения**
   (для Gmail, Яндекс Почты и mail.ru создаётся в настройках аккаунта, не основной пароль).
2. **Назначение**: любой IMAP-сервер, куда переносите почту (Exchange, другой почтовый ящик и т.д.).
3. При необходимости задайте **период** «с… по…» и **папки** (Входящие / Отправленные).
4. Нажмите **«▶ Запустить миграцию»** и следите за журналом.

Пароли можно сохранить в профиль («Сохранить профиль») — они зашифруются DPAPI и
будут подставляться автоматически при следующем запуске.

## Как это работает

| Этап | Что происходит |
|---|---|
| Подключение | Два `ImapClient` (MailKit): источник — чтение, назначение — запись |
| Дедупликация | Собирается множество `Message-ID` из назначения; совпадения пропускаются |
| Граница INBOX | Берётся дата самого старого письма в назначении — всё, что новее, пропускается |
| Фильтры | Размер (skip, если больше лимита) и диапазон дат |
| Копирование | `GetMessageAsync`, затем `Append` с исходными флагами и `INTERNALDATE` |
| Устойчивость | Ошибки не прерывают миграцию, при обрыве соединения — авто-переподключение |

## Безопасность

- Пароли **не хранятся в открытом виде** и не попадают в репозиторий.
- Защита — `System.Security.Cryptography.ProtectedData` (DPAPI, `CurrentUser`):
  расшифровать профиль может только тот же пользователь на том же компьютере.
- Приложение не отправляет данные никуда, кроме указанных вами IMAP-серверов.
